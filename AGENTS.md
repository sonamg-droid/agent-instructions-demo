# Agent Instructions

Guidance for AI coding agents working in this repository.

## Ground rules

- Use Python 3.11 or newer.
- Preserve existing type hints; add type hints to new public functions.
- Run the test suite before submitting changes.
- Never commit credentials, API keys, or `.env` files.

## Style

- Prefer `pathlib` over string-based path manipulation.
- Keep docstrings short and factual.
